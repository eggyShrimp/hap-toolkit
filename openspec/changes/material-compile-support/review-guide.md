# 评审说明：轻卡高级材质编译支持（技术方案）

> 对应文档：《技术方案 - 轻卡高级材质编译支持（draft）》
> 评审对象：平台 / 引擎侧（测试侧可关注技术方案「验证方案」、本文档 §3 待决事项）

## 1. 建议的评审方式（异步预读）

1. 会前阅读技术方案全文（约 10 分钟；重点「目标与范围」「方案」）；待决事项见本文档 §3；
2. 会上逐条过 §3 的待决事项，不逐段读文档；
3. 会后将结论填入本文档的「决议记录」，并回写技术方案。

## 2. 已决事项（无需重开讨论）

| 事项 | 结论 | 出处 |
|---|---|---|
| 校验位置 | 源码阶段校验（构建链 + 编译器），诊断带源码行列号 | 「方案」 |
| 样式精度 | 消费 source map；生成与 devtool 解耦、仅内部消费、不改产物；行级精度 | 「诊断输出」 |
| 字段校验归属 | 统一收敛到 manifest schema（`solid \| custom` 枚举），方案校验不重复 | 「目标分拆」 |
| 重复拼参重构 | 纳入本次改造范围（统一请求构造器） | 「背景规范校验」 |
| 过渡版本 | 产物级 alpha 保留为过渡，源码级完成后更新 alpha | design.md |
| 回滚 | 移除校验接入（上下文透传与编译器规则）即恢复原编译行为 | design.md |
| 不适用项 | autofix、baseline、能力级别检查（原因见 `toolchain-capabilities.md`） | `toolchain-capabilities.md` |
